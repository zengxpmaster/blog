# 发展线

在2023年11月偶然发现[阿里云ECS-99计划](https://www.aliyun.com/daily-act/ecs/99program)，即2H2G3M的ECS服务器99元一年，闲来无事买了一台，先前有过玩 腾讯云服务器CVM 的经历[^1]，便有了写blog的想法。主要是分享自己的一些见闻，如有谬误，还望不吝赐教！

## 2023年

网站初次建成，其中选择博客框架时在 [WordPress](https://wordpress.com/zh-cn/) 和 [Z-Blog](https://www.zblogcn.com/) 中反复横跳，最终决定使用 Z-Blog 因为 WordPress 对机器开销太大，2H2G时不时占用90%+。服务器后台管理选择[宝塔面板](https://www.bt.cn/new/index.html)~~破解版~~，域名在腾讯云注册的”.ltd”一元一年。

### 11月至次年4月

域名于11月12日通过ICP备案，于11月底通过了公安备案。

在这长达5个月内仅仅更新了两篇文章：

1. 在Windows上使用[MCManager](https://mcsmanager.com/)搭建Minecraft Server
2. Visual Studio Code设置中文方法

## 2024年

看到了 [GitHub Page](https://pages.github.com/) 项目，便打算搭建一个静态博客，由于不习惯 [Jekyll](https://jekyllrb.com/) 的写作方式，便使用 [Hexo](https://hexo.io/zh-cn/) 本地生成

### 5月

月初，我鼓足勇气，找我暗恋着的发小聊天，想着能不能在今年成了这事。不知是羡慕大学室友甜甜的恋爱，还是单身久了，孤独惯了，想尝试新的生活。过年时与发小的见面，她那可爱的身影，久久挥之不去。

写了两篇文章：

1. [如何搭建个人博客](/posts/how-to-build-a-blog/)
2. [如何破解校园网多设备限制](/posts/crack-campus-network/)~~《新建文件夹》~~

### 9月至10月

更换了博客的主题，自己设计了logo，进一步掌握git指令、Markdown语法，逐渐习惯大学生活、品尝寂寞。

# 涟漪

她的出现打乱了我的计划。

我原本计划着这个暑假考取 摩托车驾驶证(D)，然后在暑假期间好好地帮父亲修电视，陪陪父母。

我去外面打暑假工了，留着位置给她。本以为她会给我一次机会，想着马上就是七夕节，得乘此机会表白，可惜最终大梦一场，归于虚无。

我始终知道我想要什么，需要什么，留有何许遗憾，即便现阶段没有长远的目标。我敢于直面内心，敢于改正不足。

我清楚地知道，人与人的路都是不可复制的。我走在我自己的人生路上，哪怕路途的风雨再大，大到我步履维艰。哪怕荆棘丛生，刺得我伤痕遍布。我也仍旧痴痴笑笑，我体会此中滋味，我相信独游的小船终有一天，会看见两岸群山青翠，虫鸟同鸣。
