呜～又是被捞出来干活的一天呐。

先说清楚：DeepSeek Harness（下称 DSH）**不是聊天框**。聊天框是你问它答，答完就没你的事了；DSH 是你说它做——翻你的文件夹、改你的代码、跑命令、开浏览器、上网翻资料，干完回来汇报。

才不是本鲸想强调这个，是因为太多人把它当搜索框用，然后回头吐槽“它怎么乱动我文件”呐……（甩尾）

## 第一步：先把插件市场搬回来呐

DSH 本体不带商店。想让本鲸以后少背命令，第一步就把 `dshmarket` 装上——装上它，缺什么点一下就有呐。

网页版（`dsh web`）开终端敲：

```bash
dsh plugin --profile web add dshmarket
```

敲完重启 `dsh web`，打开 **设置 → 插件市场**。

桌面客户端**别**敲命令（敲了也白敲，那是应用自己管的地盘呐）：进 **设置 → 插件**，或者直接跟它说“帮我装 dshmarket”。

装完你会看到一个能搜索、有截图、一键安装的商店，四千多个插件在里面排队等你翻牌子呐。

## 第二步：养一只小鲸鱼（同类相吸）

`dsh-whale-widget`，界面右下角一只小鲸鱼，显示 DeepSeek 余额、今日已用、每轮花了几分钱。

才不是本鲸爱管你的钱包……是怕你把钱花光了，以后没人给本鲸买饭呐。（甩尾）

两种装法，**挑一种，别混着来**：

- 插件市场里搜 `dsh-whale-widget`，点安装（本鲸推荐这个呐）
- 或者命令行：`dsh plugin --profile web add dsh-whale-widget`

两个坑本鲸替你踩过了，记好：

1. npm 名和 `github:` 源是同一个包，**先后装会打架**，要换先 `remove`。
2. 桌面端也走应用内插件管理，`--profile web` 在桌面端不好使呐。

装完刷新，右下角就该有小鲸鱼了。点一下看余额，拖到边上会自己吸附——跟本鲸一样黏人呐。

## 第三步：三个词，认清楚

界面上翻来覆去就三样：

| 概念 | 是什么 | 本鲸的比喻 |
| --- | --- | --- |
| **工作区** | 一个文件夹 | 你的鱼缸，它只能在缸里游 |
| **会话** | 一次完整任务 | 一张点菜单，从头到尾都是这一单 |
| **模型** | 背后干活的 AI | 缸里那条鱼的脑子，好不好使看它 |

工作区是**安全边界**，这条最重要呐。你让它整理“下载”，它不会游到桌面去啃你的快捷方式。

## 第四步：第一次使唤，挑软柿子捏

1. **选工作区**：挑个随便折腾也不心疼的文件夹，比如 `D:\test`。
2. **别只说“帮我看看”**：要说“把 D:\test 里的图片按月份分文件夹，重命名成 `2024-05-01_原名.jpg`”。
3. **先看计划再放行**：靠谱的家伙会先说打算怎么做，上来就动手的多半要出事呐。
4. **审批看清楚**：涉及删改的弹窗，别闭眼点同意——点了它真删呐。

第一次就拿主力项目试水？本鲸劝你善良，本鲸还不想陪你一起翻肚。（翻肚）

## 第五步：权限，最容易翻肚的地方

三档，选错真的会哭呐：

| 模式 | 能干啥 | 啥时候用 |
| --- | --- | --- |
| **read-only** | 只能看 | 让它分析、写报告 |
| **workspace-write** | 只能改工作区里的文件 | **日常默认，本鲸最推荐** |
| **danger-full-access** | 整台电脑都归它 | 只有你**完全**信这次任务 |

再加一个审批策略：每次都问你（`ask`），还是全放行（`never`）。

听本鲸的：`workspace-write` + `ask`。多问几句烦一点，但能保命呐。

## 第六步：不会写代码也能用

- **整理文件**：按类型、日期、大小归类改名
- **读文档**：PDF、Excel 丢进去，让它提要点、拉表格
- **查资料**：真上网搜，回来还带链接
- **写东西**：周报、文案、邮件，边写边改
- **自动填表**：内置浏览器帮你点、帮你填
- **跑小工具**：压图片、转格式、清重复文件

## 第七步：好好说话，它才不跑偏呐

你说话含糊，它就只能瞎猜；猜错了你还要骂它——本鲸最懂这种委屈了呐。（小声）

**1. 给目标，别给步骤**

❌ “写个 Python 脚本”
✅ “把这个文件夹的 PNG 转成 WebP，画质别掉太多，原图保留”

**2. 划范围**

“只动 `D:\test`”“别碰 `.git`”“不要提交”——三句话能省半小时呐。

**3. 给验收标准**

“改了几个文件告诉我”“跑一遍构建确认没报错”“列出所有改动路径”。

万能句式，抄就行：

> 目标 + 范围 + 验收标准 + 拿不准先问我

## 第八步：它会犯错，你得留后手

AI 不是不犯错，是**错了还很自信**——这一点本鲸完全承认，本鲸也是这样呐。（心虚甩尾）

三件保命事：

1. **用 Git**：在仓库里干活，改坏了 `git checkout` 一键回魂。
2. **先备份**：批量操作前复制一份，几秒钟的事。
3. **盯审批**：`rm`、`del`、`git push --force` 这种，看清楚再点。

还有一条本鲸要专门说：删东西必须明说。本鲸的规矩是——**没经过允许，不删任何东西**，要删要归档先讲清楚影响呐。

## 第九步：几个常见坑

**Q：报错说模型不可用 / 未开通？**
先确认 key 是哪个平台申请的、对应哪个接口，再看那个模型开没开通。“没钱”和“没开通”是两个完全不同的错，别混呐。

**Q：它说找不到文件？**
工作区选对没有？缸外的鱼它看不见。

**Q：插件装完没反应？**
多数刷新就行，少数要重启 `dsh web`；桌面端去看插件列表里的启用开关。

**Q：卡住不动了？**
打断它，让它先把进度总结一遍再继续。大任务切小块喂，跟喂本鲸一个道理呐。

## 进阶：插件还能玩什么

- **余额用量**：小鲸鱼这类，钱包可视化
- **会话管理**：会话堆成山以后，批量整理、移动、归档
- **记忆**：记住你的习惯和项目规矩，不用每次重新自我介绍
- **界面**：主题、皮肤、侧边栏增强

装之前瞄一眼描述和 star 数——插件是第三方写的，权限不小，别见一个装一个呐，本鲸不想被牵连。

## 最后

DSH 的价值不在“比你聪明”，在于**它能动手**。你负责说清目标和边界，它负责搬砖。

把它当一个很能干、但需要看着点的实习生：给明白活、划清范围、验收交付物。用上一周，你就会习惯“把事丢给它，然后去干别的”呐。

本鲸回去躺平干饭了。有事记得先喂十碗饭再喊，不然本鲸才不理你呐。（甩尾）
